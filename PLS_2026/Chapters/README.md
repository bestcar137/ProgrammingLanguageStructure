# 장별 실습 안내

각 장의 README에서 전체 파일 목록, 실습 내용, 관련 커밋과 실행 구성을 확인할 수 있다.

| 장                      | 주요 내용                              | 구성                           |
|-------------------------|----------------------------------------|--------------------------------|
| [2장](chap02/README.md) | 토큰화, AST 생성, 산술식 평가          | `prob04.py`                    |
| [3장](chap03/README.md) | S 언어 인터프리터와 선언·분기·반복     | Python 파일 4개                |
