## 파일 내부 구성

| 구성 요소                       | 역할                                                               |
|---------------------------------|--------------------------------------------------------------------|
| `TOKEN_TYPES`, `Token`, `lex()` | 정규식으로 정수, 사칙연산 기호, 괄호를 토큰화하고 공백을 건너뛴다. |
| `Parser.factor()`               | 정수와 괄호로 둘러싸인 식을 처리한다.                              |
| `Parser.term()`                 | 곱셈·나눗셈을 처리한다.                                            |
| `Parser.expr()`                 | 덧셈·뺄셈을 처리하여 튜플 기반 AST를 만든다.                       |
| `evaluate()`                    | AST를 재귀적으로 평가한다. `/` 토큰은 Python의 `//`로 계산한다.    |
| 메인 코드                       | `3 + 5 * (10 - 2)`의 토큰 목록, AST, 결과 43을 출력하는 예제이다.  |

## 실행과 참고 사항

이 폴더에서 `python prob04.py`로 실행한다. Python 표준 라이브러리 `re`를 사용하며 예제 식은 파일 하단의 `s_code`에 들어 있다.

현재 파서는 `expr()` 호출 후 남은 토큰을 검사하는 절차가 없고, `factor()`에서 예상 밖 토큰을 만났을 때의 오류 처리도 제한적이다. 예제의 구조와 연산자 우선순위를 살펴보는 용도로 구성되어 있다.
