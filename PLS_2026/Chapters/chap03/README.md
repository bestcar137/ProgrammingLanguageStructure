# 3장 실습 파일 구성

Python으로 구현한 S 언어 인터프리터에 여러 예제 프로그램을 넣어 선언, 대입, 지역 범위, 입력, 조건문과 반복문을 학습한다.

## 검토한 커밋

2026-11-12 기준 현재 소스와 `94961e2`(2026-10-29)의 저장소 통합 내용을 확인했다. 이 커밋에서 네 파일이 현재 경로에 포함되었다. 파일 간 비교 결과 인터프리터 구현은 같으며, 하단
`s_code`의 예제 프로그램이 다르다.

## 파일별 실습 내용

| 파일           | 내장된 S 언어 프로그램                                                                                   |
|----------------|----------------------------------------------------------------------------------------------------------|
| `S_Program.py` | `x = 10`, `y = 20`을 선언하고 합계 30을 출력한다.                                                        |
| `prac02.py`    | `let ... in ... end` 안에서 `x = 0`을 선언하고 2를 더해 출력한다.                                        |
| `prac03.py`    | 정수 `x`를 입력받고 if·then·else로 절댓값을 구해 출력한다.                                               |
| `prac04.py`    | 정수를 입력받아 while로 팩토리얼을 계산한다. 0 또는 음수 입력에서는 반복을 건너뛰어 초기값 1을 출력한다. |

## 공통 내부 구성

| 구성 요소                            | 역할                                                                                     |
|--------------------------------------|------------------------------------------------------------------------------------------|
| `TOKEN_TYPES`, `Token`, `tokenize()` | 예약어, 식별자, 정수·문자열, 연산자, 구분 기호를 토큰으로 나눈다.                        |
| `Parser`                             | 선언, 대입, 블록, let, if, while, read, print와 식을 튜플 기반 AST로 만든다.             |
| `Interpreter`                        | 스코프 목록으로 변수값을 관리하고 AST를 실행한다. let 진입·종료 시 범위를 추가·제거한다. |
| `s_code`                             | 각 파일이 실행할 S 언어 예제 문자열이다.                                                 |
| `SHOW_TOKENS`, `SHOW_AST`            | True로 바꾸면 토큰과 AST를 출력한다. 기본값은 False이다.                                 |

## 실행과 참고 사항

이 폴더에서 `python S_Program.py`, `python prac02.py`, `python prac03.py`, `python prac04.py`로 각각 실행한다. `prac03.py`와
`prac04.py`는 정수 입력을 받는다. 외부 패키지 없이 Python 표준 라이브러리 `re`를 사용한다.

선언 문법에는 int·bool·string이 있으며 실행기는 Python 값으로 데이터를 저장한다. 선언 타입을 엄격히 검사하는 단계는 구현되어 있지 않다. `read`는 입력을 정수로 변환하고, 나눗셈은 `//`를
사용한다. AND·OR는 양쪽 피연산자를 먼저 평가한다. 변수 검색에 실패하면 현재 구현은 0을 반환한다.
