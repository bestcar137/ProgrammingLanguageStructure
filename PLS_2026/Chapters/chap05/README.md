## 파일을 읽을 때 참고할 점

- Java 반복문 파일은 이름에 `prac6`가 들어 있지만 현재 위치는 `prac04/src`이다.
- `prac01.c`의 일부 주석과 출력 문구는 비교·최댓값을 설명하지만 실제 식에는 `&`와 `&=`가 사용되어 있다. 비트 연산의 실제 동작을 기준으로 읽어야 한다.
- `prac5.py`의 OR 예제는 `x = 0`이므로 오른쪽 항을 평가해 `y`가 증가한다. 해당 분기의 출력 문구는 앞부분만 평가한다고 적혀 있어 코드 동작과 차이가 있다.
- `prac06`의 네 구현은 반복 종료 후 `sum = 105`, `n = 15`를 출력하는 구조이다. 마지막으로 더한 정수는 14이고, `n`은 증가 연산 이후의 값이다.

## 빌드 구성

저장소 루트의 `CMakeLists.txt`는 C11과 C++17을 사용하며, 각 실습을 독립 실행 대상으로 등록한다. 대상 이름은 `PLS_2026_Chapters_chap05_` 접두사 뒤에 실습 이름이 붙는다.
예를 들어 `prac06/prac6.cpp`의 대상은 `PLS_2026_Chapters_chap05_prac6`이다.

`prac07`의 두 C++ 파일은 `void main()`을 사용하므로 CMake 기본 전체 빌드에서 제외되어 있다. GCC로 빌드하려면 반환형 수정이 필요하다는 설명이 CMake 파일에 기록되어 있다.

Python 파일은 Python 인터프리터로 실행하며, `prac05`의 대입 표현식 `:=`에는 Python 3.8 이상이 필요하다. Java의 `prac4.java`에는 실행 진입점이 있으며, IntelliJ
모듈 설정은 `prac04/src`를 테스트 소스 폴더로 등록한다.
