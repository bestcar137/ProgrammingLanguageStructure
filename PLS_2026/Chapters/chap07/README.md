## 1. 숫자 (정수)와 문자 (열)의 혼합 연산

강의 자료는 C/C++를 약한 타입 언어, Python을 강한 타입 언어로 구분해 혼합 연산을 비교한다. C++에서 `ch + num`은 `char`가 정수로 승격되어 계산된다. Python에서 `ch`는 길이 1의
문자열이고, 정수와 바로 더하면 `TypeError`가 발생한다.

- `ord()`는 길이가 1인 문자를 유니코드 코드 포인트 값으로 변환한다. `ord('A')`는 `65`다.
- `chr()`는 유니코드 코드 포인트에 해당하는 단일 문자로 변환한다. `chr(65)`는 `'A'`다.

두 예제의 출력은 `정수 결과: 70`과 `문자 결과: F`다.

## 2. 실수 (float) 데이터의 손실

C의 `int int_pi = pi`는 묵시적 형변환이다. 소수부가 잘려 `int_pi: 3`이 출력된다. Python의 `x = f_val`은 같은 값에 이름을 붙이는 대입이라
`<class 'float'> 3.141592`가 출력된다. `str(f_val)`을 문자열과 결합한 결과는 `<class 'str'> 값: 3.141592`다.

실습 1과 2의 Python 코드는 자료에 표시된 `TypeError` 발생 줄을 주석 처리했다.

## 3. 실수 (float) 데이터의 타입 재해석

C 예제의 첫 번째 연산은 실수의 바이트를 부호 없는 정수로 읽는 포인터 강제 형변환이고, 두 번째 연산은 실수 값의 소수부를 버리는 일반 값 형변환이다. Python에서는 `struct.pack('>f', f)`로
단정밀도 실수를 4바이트에 저장하고, `struct.unpack('>I', ...)`로 같은 바이트를 부호 없는 정수로 읽는다. 일반 값 형변환에는 `int(x)`를 사용한다.

| 연산                   | Windows MinGW Debug 및 Python에서 확인한 값 |
|------------------------|---------------------------------------------|
| `0.1`의 비트 재해석    | `1036831949` (`0x3DCCCCCD`)                 |
| `0.1`의 일반 값 형변환 | `0` (`0x00000000`)                          |

C 실습의 포인터 캐스트는 자료의 코드 그대로다. `float` 객체를 `unsigned int *`로 역참조하는 동작은 C 표준에서 정의되지 않는다.
